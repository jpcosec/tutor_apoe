# Reversal

## Descripción

La reversión es un mecanismo fundamental para "deshacer" un proceso, operando incluso sobre aquellos recuperados por una desencapsulación. A diferencia de la interiorización, que forma un proceso a partir de una acción, la reversión permite invertir este proceso o uno resultante de la manipulación de un objeto, siendo esencial para comprender construcciones matemáticas como la función inversa o la antiderivación.
