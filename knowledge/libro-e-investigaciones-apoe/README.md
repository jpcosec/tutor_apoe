# Libro APOE e investigaciones APOE

Este módulo conserva el catálogo de fuentes que pueden fundamentar el Tutor
APOE. Se distinguen dos colecciones:

- **Libro APOE:** libros y capítulos de referencia.
- **Investigaciones APOE:** artículos, tesis, informes y estudios empíricos.

Cada registro conserva título, autoría, año, tipo, tema, cita, ubicación y
notas de curaduría. Agregar una referencia al catálogo no la transforma por sí
misma en conocimiento del tutor. Para incorporar afirmaciones a la base se
debe cargar la fuente, proponer átomos con su cita y revisarlos antes de
publicarlos.

## Uso

Con el visor local en ejecución, abrir `/bibliografia`. Desde allí se puede
agregar la ficha bibliográfica de una fuente y ver los registros separados por
colección. Si todavía no se cuenta con el archivo, se puede registrar una cita
o enlace en **Ubicación** y dejar una nota pendiente de verificación.
