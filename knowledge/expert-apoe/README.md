# Módulo experto APOE

Aquí se reúnen repositorios personales de especialistas y sus conversaciones
estructuradas. Cada repositorio vive en la carpeta experts y conserva perfil,
índice de conversaciones y transcripciones.

Las conversaciones no modifican los átomos fuente automáticamente. El
protocolo operativo es **LAETEC v1.0** y se conserva en `protocol.json`.
Solicita conformidad y código de participante, recorre P01–P12 de a una
pregunta, permite hasta dos repreguntas predefinidas cuando la cobertura es
parcial y pide validar la síntesis antes del cierre.

Cada turno conserva identificador, cobertura y referencias a preguntas
relacionadas. Fuente de diseño: `Instrucciones_Codex_Entrevista_APOE.md`;
referencia declarada: Arnon et al. (2014), *APOS theory*.
