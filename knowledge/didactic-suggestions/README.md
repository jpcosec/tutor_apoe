# Repositorio de sugerencias didácticas

Este repositorio conserva propuestas de actividades y ejemplos para la enseñanza.
No son átomos fuente de la KB APOS ni se presentan como afirmaciones verificadas.

Cada propuesta debe indicar:

- dominio y concepto matemático;
- la solicitud que la originó;
- los átomos fuente usados, si corresponde;
- su estado de revisión.

Las propuestas generadas desde el visor tienen estado `proposed`. Si falta el
dominio o el concepto, el visor debe pedir esa información en vez de inventar
un ejemplo.
