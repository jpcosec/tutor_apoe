# Action

## Descripción

La Acción es una de las estructuras mentales centrales en APOS, representando las transformaciones iniciales de un concepto matemático que requieren una guía externa explícita y una ejecución paso a paso. A diferencia de un Proceso, donde las transformaciones ya pueden ser imaginadas y controladas internamente, la Acción describe la fase en la que cada etapa es dirigida externamente y no puede ser aún realizada mentalmente.
