# Object

## Descripción

El Objeto representa la encapsulación de un proceso en una entidad mental estática, permitiendo tratarlo como una totalidad sobre la cual aplicar nuevas acciones y realizar razonamientos. A diferencia de una Acción o un Proceso, que implican una transformación dinámica, el Objeto es la cosificación de dicha transformación, siendo un componente crucial para la construcción de un Esquema.
