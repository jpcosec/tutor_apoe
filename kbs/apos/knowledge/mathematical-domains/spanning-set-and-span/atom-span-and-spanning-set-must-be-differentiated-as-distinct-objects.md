# Span y conjunto generador deben diferenciarse como objetos distintos

## Respuesta

El libro subraya que una parte importante de la construcción conceptual consiste en diferenciar el conjunto generador de su espacio generado, es decir, distinguir spanning set de span.

## Procedencia

Arnon et al. (2014), cap. 4 §4.2.3, p. 48. «A student who has an Object conception of spanning set can make comparisons to decide whether a given vector space can be generated by different spanning sets independently of the size of the set or their speciﬁc elements.»
