# El Objeto es una estructura mental central en APOS

## Respuesta

APOS incluye el Objeto como una estructura mental que permite tratar un proceso matemático como una entidad sobre la cual pueden aplicarse nuevas acciones y razonamientos.

## Procedencia

Arnon et al. (2014), cap. 3 §3.2.3, pp. 32–33. «Encapsulation occurs when an individual applies an Action to a Process, that is, sees a dynamic structure (Process) as a static structure to which Actions can be applied.»
