# La tematización ocurre al aplicar acciones a un esquema

## Respuesta

La tematización de un esquema, dentro de la Teoría APOS, ocurre cuando se pueden realizar acciones sobre él, tales como operar, comparar con otros esquemas, descomponerlo en sus componentes o reconstruirlo. Esto transforma el esquema en un objeto sobre el cual se pueden aplicar procesos.

## Procedencia

Fuente: Arnon et al. (2014) APOS Theory (p. 137). Fragmentos: `source-arnon-et-al-2014-apos-theory-chunk-319`. Cita: «thematization is the mechanism by which a Schema is transformed into an Object so that it is possible to perform Actions on it or to apply Processes to it.».

## Justificación

El átomo existente define qué es la tematización. Este átomo complementa esa definición explicando las condiciones específicas bajo las cuales ocurre la tematización de un esquema en la Teoría APOS, detallando los tipos de acciones que se pueden realizar sobre él.
